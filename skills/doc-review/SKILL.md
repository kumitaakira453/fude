# ドキュメントレビュー対応スキル

人間が mdglow で付けたレビューの指摘を読み取り、指摘に基づいてドキュメントを修正する。

## 引数

| 引数 | 必須 | 説明 |
| --- | --- | --- |
| 対象ファイルパス | いいえ | 修正対象の Markdown ファイル。省略時は直前に Write または Edit で作成・編集したファイルを対象とする |

## 前提

- `mdglow` に PATH が通っていること。通っていなければ次で張る

  ```bash
  mkdir -p ~/.local/bin
  ln -sfn "/Applications/mdglow.app/Contents/MacOS/app" ~/.local/bin/mdglow
  ```

- 人間が mdglow で対象ファイルに指摘を付けてあること

台帳はマシンに 1 つで、プロジェクトごとには分かれていない。`--project` でプロジェクトの
ルートを渡して絞り込む。`--file` は絶対パスでも相対パスでもよい。

## 手順

### 1. 指摘の取得

未解決の指摘を一覧する。

```bash
mdglow review list --project [プロジェクトルート] --file [対象ファイルパス]
```

既定は未解決のみ・Markdown 形式。解決済みも見たいときは `--status all`、機械的に扱いたい
ときは `--format json` を足す。

指摘が 0 件なら「未解決の指摘が見つかりません」と伝えて終了する。

### 2. 指摘の読み方

各指摘には、指摘した時点の本文（`指摘時の本文:`）と、その箇所が**今どうなっているか**が
併記される。修正前にこの状態を必ず確認する。

| 表示 | 意味 | 取るべき行動 |
| --- | --- | --- |
| 対象はまだ書き換わっていません | 指摘された箇所が当時のまま残っている | そのまま修正する |
| 対象は指摘のあと書き換わっています | 既に別の内容になっている | 併記される現在の本文を読み、指摘が今も当てはまるか判断してから直す |
| 対象は削除されています | 該当箇所が無くなっている | 指摘が解消済みでないか確認する。解消済みなら修正せず返信だけ行う |
| 対象の位置を特定できていません | 本文が大きく変わり、対応する箇所を追えなかった | 引用文を手掛かりに自分で探す。見つからなければ推測で直さず、その旨を返信する |
| ファイルが見つかりません | 移動・改名された | 修正せず、ユーザーに確認する |

修正は Edit ツールで最小限の変更にとどめる。

### 3. 返信と解決

修正した各指摘に、まず何をしたかを返信する。

```bash
mdglow review reply --thread [指摘ID] --author AI --body "[修正内容の要約]"
```

指摘 ID は一覧の `### 指摘 #xxxxxxxx` の `#` に続く 8 桁。

対応が完了したものを解決済みにする。

```bash
mdglow review resolve --thread [指摘ID] --by AI
```

判断がつかず修正しなかった指摘は**解決済みにしない**。返信だけ残して人間に委ねる。

### 4. 版の記録

そのファイルへの対応が一通り終わったら、現在の内容を版として記録する。次のレビューで
「どこが変わったか」を出すための基準になる。

```bash
mdglow review commit --file [対象ファイルパス] --message "[対応の要約]"
```

記録済みの版は `mdglow review versions --file [対象ファイルパス]` で新しい順に確認できる。

### 5. 再レビュー依頼

修正サマリーをユーザーに提示する。

```
## 修正サマリー

| 指摘 | 状態 | 対応 |
|------|------|------|
| #xxxxxxxx | [対象の状態] | [修正内容] |

mdglow で再度確認してください。
```

修正しなかった指摘があれば、理由を添えて別の表に分けて示す。

## 注意事項

- **推測で直さない**: 対象の位置を特定できていない指摘は、引用文で探して見つからなければ
  返信で状況を伝える。それらしい箇所を当てずっぽうで書き換えない
- **解決済みにするのは実際に対応したものだけ**: 返信だけして解決しない選択を恐れない
- **版の記録は対応が終わってから**: 途中で記録すると、次のレビューの基準が中途半端になる
