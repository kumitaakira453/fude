# 外部編集との合流（設計案・未着手）

書いている最中に、別のエディタや AI エージェントが同じファイルを書き換えたときの
扱い。**いまは未実装で、古い版で上書きする経路が残っている。**優先度を下げて
保留した時点の設計をここに残す。

## いま起きていること

外からの書き換えは `src/hooks/useWatcher.ts` が拾って `reloadFile()` を呼び、
`contentCacheAtom` が新しくなる。読むときはこれで描き変わる。ところが編集中は、

- `BodyEditor` は `key={path}` で組み立ては一度きり（`useEffect` の依存が `[]`）。
  path が変わらないので作り直されず、**古い本文のまま**
- `exitEdit()` は `draft !== raw` なら保存する。外で変わった直後は当然「違う」ので、
  **古い draft で新しいファイルを上書きする**（`src/components/DocPane.tsx`）
- `saveFile()`（`src/hooks/useWorkspace.ts`）はディスクを見ずに無条件で書く

自動保存を入れたので未保存の窓は 1 秒未満になったが、**窓が閉じたわけではない**。

## 想定する相手は AI エージェント

人が別のエディタで開いている状況より、**エージェントが節や全文をまとめて
書き換える**のが実際の使い方。行単位の差分がそのまま効く形なので、3 者マージが
素直に当たる。

## Yjs（CRDT）は効かない

Yjs / y-prosemirror は**両側がピア**であることが前提。編集の履歴を持ち合って
合流させる仕組みなので、相手も Yjs でなければならない。

こちらの相手はファイルを丸ごと置き換えるだけで履歴を持たない。無理に使うなら
「新しいファイルを読んで構造の差分を Yjs 操作へ翻訳する」層が必要で、それは
3 者マージを書くのと同じ手間の上に CRDT の重さが乗る。

一方、手元には**土台（読み込んだとき）・手元（draft）・外（ディスク）の 3 つが
揃っている**。これは git のマージと同じ形。

将来 fude の窓を 2 つ開いて同じファイルを同時に書く形にするなら、そのときは
両側がピアなので Yjs が正解になる。

## 設計

### 1. 3 者マージ（`src/lib/mergeText.ts` 新規）

`node-diff3`（依存なし、iD エディタなどで実績あり）を包む。

```
merge(base, ours, theirs) -> { text, clashes }
```

- 別々の場所を直していれば**両方入る**
- 同じ行を両方が直したときだけ衝突。そこは**手元を残し**、件数を返す
- 文書に `<<<<<<<` のような印は入れない（読み物のファイルに残ると事故になる）

### 2. 書く前にディスクを確かめる（`src/hooks/useWorkspace.ts`）

`saveFile(rel, text, base?)` に土台を渡せるようにし、書く直前に `readFile()`
（`src/lib/fsAccess.ts`）で今の中身を読んで `base` と比べる。違っていれば
**書かずに**ディスクの中身を返す。監視が取りこぼしても効く最後の砦。

### 3. 編集面の土台を持ち、外の変更を合流させる（`src/components/DocPane.tsx`）

`base`（編集を始めたとき、および保存が通ったときの本文）を持つ。`raw` が
変わったら（編集中のみ）:

- `raw === base` … 自分の保存が返ってきただけ。何もしない
- `draft === base` … 手元に未保存が無い。**そのまま取り込む**
- それ以外 … **3 者マージ**して結果を採用し、そのまま保存する

取り込み / マージのあとは `BodyEditor` を作り直す（`key` に世代を足す）。
見ていた場所は既にある viewpoint の仕組みで戻る。

### 4. 知らせ方

自動で解けたときは何も出さない。衝突で手元を残した箇所があるときだけ帯に出す。

> 外の変更と N か所重なりました。手元を残しています。［外の版を読む］

**衝突しても外の版を捨てない**ことが要点。帯から取れるようにする。

## 検証

- `src/lib/mergeText.test.ts`
  - 別の場所は両方入る / 同じ行は手元が残って衝突 1 / 片方だけならそのまま /
    行の追加・削除・末尾の改行の有無
- 実機
  1. 編集中に外で別の場所を書き換える → 手元を保ったまま両方入る
  2. 編集中に外で同じ行を書き換える → 手元が残り、帯が出る
  3. 手元に変更が無い状態で外が変わる → そのまま反映され、見ていた場所も保たれる
  4. ⌘S・⌘E・タブ切替のいずれでも外の変更が消えない
